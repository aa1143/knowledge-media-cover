# 知识类自媒体封面 Skill

一套用于生成统一风格知识类自媒体封面的 Codex Skill。

它将栏目封面固定为一套可持续复用的视觉系统：**顶部分类标签、中间大标题、一张概念主图、黑白主色与暗红点缀**。

适用于：

- 公众号文章封面
- 小红书知识类封面
- 知识视频封面
- Newsletter 头图
- AI、效率、职场、商业与个人成长类内容

## 风格特点

- 冷白纸张背景
- 黑色高对比标题与插画
- 暗红色用于数字、关键词或短分隔线
- 木刻、铜版画、钢笔蚀刻与排线质感
- 顶部保留固定的分类标签，例如“AI 学习指南”
- 中间区域使用醒目的中文大标题
- 每张封面只使用一张主图，通过一个视觉隐喻表达主题
- 避免机器人、芯片、代码墙和霓虹科技风等常见 AI 套路

## 安装

将整个 `create-knowledge-media-cover` 文件夹复制到你的 Codex Skills 目录：

```text
~/.codex/skills/create-knowledge-media-cover
```

也可以将本仓库克隆或下载后，把该文件夹放入个人 Skills 目录。

## 使用方式

在 Codex 中直接调用：

```text
使用 $create-knowledge-media-cover 生成一张 3:4 封面。
分类标签：AI 学习指南
标题：普通人到底怎么学 AI？照着这 4 步就够了
```

也可以使用自然语言：

```text
按照“知识类自媒体封面”的固定风格，给这篇文章生成一张公众号横版封面。
分类标签是“效率工具”，标题是“真正拉开差距的，不是工具数量”。
```

## 建议提供的信息

每次生成时，最好提供以下内容：

1. **分类标签**：例如 AI 学习指南、效率工具、认知升级；
2. **主标题**：封面中最重要的文字；
3. **画面含义**：希望主图传达的核心观点；
4. **输出比例**：例如 3:4、公众号横版 900×383。

如果没有指定画面，Skill 会根据标题提炼一个单一视觉隐喻。

## 固定视觉规范

| 项目 | 规范 |
| --- | --- |
| 背景色 | 冷白色 `#F7F7F5` |
| 主色 | 近黑色 `#090909` |
| 点缀色 | 暗红色 `#8E1B16` |
| 标签位置 | 顶部或左上方 |
| 标题位置 | 中部视觉核心区域 |
| 插画数量 | 一张主图、一个核心隐喻 |
| 插画风格 | 木刻、铜版画、钢笔蚀刻、交叉排线 |

## 自定义

你可以替换 `assets` 中的参考图，形成自己的系列视觉；也可以在 `SKILL.md` 中修改默认颜色、标签位置、字体层级和常用输出比例。

建议保留“一张主图表达一个意思”的原则，这是整套封面保持统一、清晰和易识别的关键。
