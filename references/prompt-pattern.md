# Prompt pattern

```text
Use case: ads-marketing
Asset type: Chinese knowledge-content cover, [platform, ratio, dimensions]
Primary request: Create a consistent editorial cover for [topic]. Express [central idea] through one conceptual image.
Concept: [one action-driven metaphor; specify one dominant subject or scene].
Style/medium: monochrome woodcut, copperplate engraving, pen etching, dense crosshatching and stippling, refined ideas-magazine illustration.
Composition/framing: [vertical or wide layout], category label at top, large central headline, one main illustration, generous negative space, safe margins, strong thumbnail readability.
Color palette: cool white #F7F7F5, near-black #090909, dark red #8E1B16 used only for [one numeral, keyword, or divider].
Text (verbatim): category label “[label]”; main title “[title]”.
Text hierarchy: category label is a smaller persistent column marker; main title is the visual center and must remain legible at thumbnail size.
Constraints: exact Simplified Chinese text, one metaphor, one dominant illustration, no additional words, no logo, no watermark.
Avoid: generic robots, brains, chips, circuit boards, code walls, neon cyberpunk, glossy 3D, sepia paper, clutter, explanatory labels.
```

For a subtitle, include it only when the user provides one or the title naturally has a question-and-promise structure. Keep it subordinate to the main title. Use the red accent once.
